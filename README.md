# Rugby Tactics Board — Les Implacables

Private tactical board for creating, animating, saving and sharing rugby plays.

## Included

- Smooth phase playback with interpolated player and ball movement
- Pitch In, Pitch Middle, Pitch Out and Lineout board views
- Lineout and Scrum setup templates
- Local save/load, JSON export/import and share links
- Les Implacables 1993 transparent badge

## Run locally

Open `index.html` in a browser.
